# Weiqing Lu — Academic Website

A personal academic homepage covering research publications, engineering projects, and awards.

Website: https://luweiqing.github.io/

## Local preview

Open `index.html` in a browser. The page works without installing packages or running a build.

For development with an HTTP preview, run `python -m http.server 4173 --bind 127.0.0.1` from this directory and open `http://127.0.0.1:4173/`.

## Files

- `index.html`: profile, research, project, and award content.
- `styles.css`: responsive page layout and styling.
- `app.js`: figure viewer, section navigation, and email copy control.
- `assets/research/`: display copies of research figures and portrait.

The site uses relative asset paths and is hosted at the root of GitHub Pages.

The homepage is organized around Interest, Publications, Engineering Projects, Awards, and Contact.

Internal source notes, preview images, and review files are kept under `working/` and excluded from Git.
